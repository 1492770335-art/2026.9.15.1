# EXP-0003 决策记录（BASE-GRU 官方原样）

- **一句话结论**：官方原样 GRU（2 epoch）双折 pooled 官方分数 **0.2012 / 0.2176**，双折全面超过 Ridge 与官方 MLP；成为当前最强 P0 基线，P1 优先在其上做单因素消融。

- **失败分析**：无失败；GPU 流式评估 6.9 s/日，符合在线要求。
- **下一个单变量假设**：强训练配方 GRU（更多 epoch+早停，同结构）vs 官方 2-epoch GRU——先确认训练强度带来的增益（EXP-0005），再动结构。
