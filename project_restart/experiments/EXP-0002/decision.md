# EXP-0002 决策记录（BASE-MLP 官方原样）

- **一句话结论**：官方原样 SiLU MLP（2 epoch 配方）双折 pooled 官方分数 **0.1913 / 0.2105**；与 Ridge（0.1929 / 0.2051）两折互有胜负，无一致非线性增益。KEEP 为对照基线。
- **判定**：KEEP（基线）。REJECT 作为候选提交方向（2-epoch 明显欠拟合，loss ≈ 1.0）。
- **负证据**：y2 训练 loss 两 epoch 仅 1.066→1.060，基本未学习；官方示例配方是接口演示而非强基线。
- **失败分析**：无运行失败；结果符合"示例非冠军基线"预期。
- **下一个单变量假设**：官方原样 GRU（hidden=128, window=100, lr 1e-5, batch 1024, 2 epochs）在同双折上对比（EXP-0003，TC-19）。之后以更强的独立配方（更多 epoch/早停，严格双折）作为真正竞争基线。
- **资源**：GPU ~85 s/折，峰值显存 1179 MB。
