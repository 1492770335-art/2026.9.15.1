# EXP-0015 决策记录（TC-27 新协议 K100 基线）

- **一句话结论**：内部早停协议成功实现；新协议 K100 seed42 得 FoldA 0.2228 / FoldB 0.2530，与旧协议（0.2228 / 0.2531）最大差仅 0.0001——外层验证标签未给旧模型带来实质性选择收益，新协议以零代价消除了早停的方法学隐患。

- **每目标 E**：A = 6/2/2；B = 4/2/2（B 折 y0 由旧 6 改为内层最优 4；内层 stop 轨迹：y0 峰值 0.4632@ep4，y2 ep2=0.1064 后快速衰减）。
