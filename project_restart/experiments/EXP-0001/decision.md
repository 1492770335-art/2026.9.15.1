# EXP-0001 决策记录（BASE-RIDGE）

- **一句话结论**：Ridge 基线在 Fold A/B 双折的 pooled 官方分数为 **0.1929 / 0.2051**（λ=100），经官方流式 Evaluator 逐分一致复核；gap=0/1 敏感性未见跨日标签泄漏。KEEP 作为后续模型的对照基线。
- **判定**：KEEP（Ridge 为基线，不是候选提交）。
- **负证据**：λ 网格在 1–1000 内分数差异 < 0.001（A 折 0.1926→0.1936），线性模型对正则不敏感，说明线性部分信号有限；c2（权重 0.5）的 corr 最低（A 折 0.116），是最难且权重最高的目标。
- **失败分析**：无失败；一次性产出双折结果。
- **下一个单变量假设**：官方原样 SiLU MLP 100→128→128→1（同 seed 42、同 2 epoch、同优化器配方），在相同双折上对比 Ridge——验证非线性增益（EXP-0002）。
