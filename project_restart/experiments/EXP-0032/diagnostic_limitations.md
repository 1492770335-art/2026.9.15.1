# EXP-0032 诊断局限性声明（diagnostic_limitations.md）

- 本批所有残差/互补性数值都是在**反复使用的 A/B 外层开发日期**（8–11 / 12–15）上、用冻结预测逐行对齐后计算的描述性诊断；不是独立验证，也不是可用于训练新模型的证据。
- 未使用训练期 cross-fitted OOF（当前项目不存在）；A/B outer 已多次参与选型，任何基于它的「发现」都存在严重适应性选择偏差。
- Market/K16 互补性的残差相关（0.01~0.12）量级小、且来自同一 GRU 架构族，不能据此宣称发现了可用增量因子。
- y2 候选与冻结 y2 残差的相关为负/近零，仅说明这些候选是噪声级变体，不构成「y2 无剩余信号」的证明——y2 仍可能有 K16 架构族之外的信号，但当前证据不足以定位。
- 官方 Score 的口径（未舍入 corr 加权后 round4）已在 R0 核验；本批 raw corr 由冻结 checkpoint 批量推理重算，与记录一致。
