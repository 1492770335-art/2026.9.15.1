## 模型与训练

- 每个时刻有 50 只股票。上游模型先产生三个期限的预测。后续各层分别利用盘口变化、价格事件间隔、其他股票的观测和历史预测，学习如何调整对应目标。层与层按发布顺序执行。
- Y3 累计改善较多。模型利用此前发出的短期预测，等相应时段过去、价格变化可以观测后，再估计哪些预测信号在近期具有稳定的收益方向。该估计用于调整当前的长目标预测。
- 最后一层主要影响 Y2。将股票固定分成 5 组，每组 10 只，用另外 40 只的当期预测作为外部信号。每 96 步更新一次信号与接收组已实现价格变化的关系，同时观察第 0–5 和 5–20 步两个区间。同向的估计取较小绝对值，经训练期回归校准后加回当前预测。盘中交易时段切换时重置历史。该层在第 9–12、13–16 天两个滚动窗口分别提升 Y2 相关系数 0.00041364 和 0.00048333。
- 层的顺序、训练入口及选中的目标分支见 [stages.py](stages.py)。[train.py](train.py) 在前 16 天内重新拟合各层，并逐层生成下游需要的历史预测。[folds.py](folds.py) 按时间切点拟合，给随后的训练日期产生预测。最终回放入口读取各层拟合参数，分别对整天与截断序列推理。

## 运行

先按[基础模型说明](../../README.md)及[五步盘口版本说明](../five_tick_field_curve_v1/README.md)训练上游，保留其日张量缓存、滚动预测和模型产物。以下命令从仓库根目录运行，沿用五步盘口版的运行目录。训练使用 CUDA。

```bash
release_dir="$(pwd)/project_restart/releases/causal_16d_best"
version_dir="$release_dir/versions/basket_cash_feedback_v1"
prior_src="$release_dir/src"
run_dir="$(pwd)/local_runs/five_tick_field_curve_v1"
data_file="$(pwd)/project/project/data/public.parquet"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 POLARS_MAX_THREADS=2

python -u "$version_dir/train.py" --prior-src "$prior_src" --run-dir "$run_dir"
python -u "$version_dir/prepare_base.py" --prior-src "$prior_src" \
  --run-dir "$run_dir" --data "$data_file"
python -u "$version_dir/replay.py" --prior-src "$prior_src" \
  --run-dir "$run_dir" --report "$run_dir/basket_replay.json"
```

若上游训练时指定了自定义滚动预测位置，向 `train.py`、`replay.py` 传入相同的 `--rolling`。若日张量使用自定义缓存，将 `TULIN_CACHE` 设为该目录。此前各层完成后，支持用 `--start N` 从第 N 层恢复，或用 `--stop N` 结束本次训练。预测输入须沿用基础版的时间和股票排序。回放先对原始特征运行上一正式版，再分别对完整日和同一天的前缀重载并应用本版校正。报告包含各日行数、前缀误差、目标相关系数和合并分数。模型参数、训练数据和预测缓存由以上入口在本地生成。

## 精度核对

在本机重载各层参数，以单独生成的五步盘口版预测为起点，全量回放综合分为 **0.3731327005317729**。上一正式版的记录为 0.37212517118484645，累计提高 0.001007529347。复用已核验的上游缓存时得分为 0.37313270056673853。四天截断前缀的最大绝对误差为 1.9133091e-05。最后一层独立重训后，参数、滚动选择与预测逐项一致。
