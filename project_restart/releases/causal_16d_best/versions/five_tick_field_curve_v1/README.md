# 五步采样的订单簿变化预测

本版在 50 股联合预测器上增加三个目标的校正层，主要改善 Y3。基础预测器和前一正式版的训练入口见[上级训练说明](../../README.md)。版本依赖的上次发布提交为 `023d81475d96706f9922758cf0dbab288b2d702f`。

## 模型

- 对 Y1，从交易活动较强的股票提取同时点信号，并用训练期估计的系数调整短期预测。
- 对较长时段，分别估计每只股票相对市场的变化和 50 股共同的变化。把个股上估计的盘口状态与收益关系用于约束市场层的估计，再用滚动训练预测校准修正幅度。
- 对 Y3，先估计盘口中哪些字段的变化还无法从已观察到的核心字段解释。训练时在同一交易时段内采样未来第 20、25、30、35、40、45、50、55 步，学习当前状态能预示多少这样的变化，以及这些变化与收益的关系。推理时直接把学到的系数作用在当前及过去的观测上。每天重新开始，盘中时段边界也截断相关历史。
- 最后一层的选择发生在前 16 天内部。第 9–12 天与第 13–16 天两段滚动验证的 Y3 相关系数分别提高 0.00093506、0.00053480。八天中有七天提高，每段各去掉任意一天后该段增益仍为正。

## 复现

先按上级说明在本机训练至“Y2”最后一版，保留各阶段的训练产物。本版 `base/predictor.py` 从上级训练目录重载 **16 天**基础模型。环境、数据获取和日张量缓存的准备步骤与上级说明一致。以下命令从仓库根目录运行。

```bash
root_dir="$(pwd)"
previous_src="$root_dir/project_restart/releases/causal_16d_best/src"
version_dir="$root_dir/project_restart/releases/causal_16d_best/versions/five_tick_field_curve_v1"
run_dir="$root_dir/local_runs/five_tick_field_curve_v1"
data_file="$root_dir/project/project/data/public.parquet"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 POLARS_MAX_THREADS=2

python -u "$version_dir/train.py" --prior-src "$previous_src" \
  --cache "$previous_src/artifacts/joint_transformer/cache" --run-dir "$run_dir"
python -u "$version_dir/replay.py" --prior-src "$previous_src" \
  --data "$data_file" --run-dir "$run_dir"
```

`train.py` 先按时间顺序重建前一版在训练期的滚动预测，再拟合新增层。已有本版 `rolling.py` 生成的中间结果时，可用 `--rolling /path/to/rolling` 复用。各层选中的方案与拟合系数保存在本地运行目录。已有独立的 16 天基础模型包时，可向回放入口传入 `--base-src /path/to/causal_16d/src`。`replay.py` 遍历四个验证日，分别从特征回放整天及截断的序列，用重载的参数产生预测，再读标签打分。逐日及合并结果写入 `raw_replay.json`。

## 验证结果

第 1–16 天训练，第 17–20 天全量验证，共 936,250 行。Y1、Y2、Y3 分别对应原数据的 `y0`、`y1`、`y2`。先对四天所有行合并计算各目标的 Pearson 相关系数，再按 20%、30%、50% 加权。

| 验证数据 | 综合分 |
| --- | ---: |
| 第 17 天 | 0.41069843 |
| 第 18 天 | 0.33376218 |
| 第 19 天 | 0.36174371 |
| 第 20 天 | 0.37164478 |
| **四天合并** | **0.37212517** |

重载新增层、复用已验证上游预测所得的未四舍五入分数为 0.37212517119466015。三个相关系数分别为 0.5017477856778535、0.39183030689327203、0.3084530439822157。上次正式发布的综合分为 0.37095867568143737。按日期和 120 步时间块配对重抽样 4,000 次，两版综合分差的 95% 区间为 −0.000913 至 +0.003296。这四天已经用于多轮模型比较，对新日期的收益仍需独立数据检验。

独立从原始特征回放所得综合分为 **0.37212517118484645**，相对上次正式发布提高 0.001166495503。四个验证日的基础预测与独立基础模型包逐项一致。从前 16 天重新拟合的 10 组参数逐项一致，整天预测与对应截断序列的前缀最大绝对差为 2.1487474e-05。
